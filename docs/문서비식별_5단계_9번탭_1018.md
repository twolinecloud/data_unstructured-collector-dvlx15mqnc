## 2. 시험 문서는 레포에 담았다 (30개 · 1.6MB)

| 묶음 | 개수 | 내용 |
|---|---|---|
| 포맷지원 | 6 | 1쪽 · PII 12종 · 자리 9곳(본문 · 표 4종 · 표뒤문단 · 머리말 · 꼬리말 · 문서속성) |
| 표구조 | 14 | 8유형 docx + **깨지는 두 유형**(값분할 · 셀내줄바꿈)의 hwpx · pdf · hwp |
| 장수 | 8 | 1 · 10 · 50 · 100장 docx · pptx |
| 정답표 | 2 | 탐침 · 표 케이스 |

**왜 담는가** — hwp · hwpx 는 한글 COM 이 필요해 **클러스터에서 만들 수 없다**.
docx · xlsx · pptx 는 만들 수 있지만, 같은 묶음을 쓰지 않으면 채팅 실화면 시험과
숫자를 맞출 수 없다. 그래서 한 벌을 **고정 자산**으로 둔다.

**zip 에 정답표를 늘 같이 넣는다.** 정답 없이 문서만 내려가면 채팅 실화면에서 같은
파일로 시험해도 채점을 못 한다 — 기획 §0-6 의 요구가 이것이다.
zip 은 `ZipOutputStream` 으로 만든다(의존성 없음).

## 3. 배선 — 왜 수집기가 중계하는가

```
화면 ──→ 수집기 /api/v1/voice/simulator/doc-deid/detect?path=A|B
                  └─→ 커넥터 /api/v1/deid/air/detect-file   (경로 A)
                  └─→ 커넥터 /api/v1/deid/doc/detect        (경로 B)
                           └─→ AI-R
```

AI-R 자격증명·프로파일은 **커넥터만** 가진다. 화면이 AI-R 을 직접 부르면 401 이다.
그래서 수집기가 얇게 중계한다 — 화면이 수집기에서 열리든 admin-fe 사본에서 열리든
같게 동작해야 한다.

**커넥터 응답을 그대로 내려준다.** 커넥터가 이미 AI-R 실패를 200 으로 감싸
`airStatus`·`elapsedMs` 를 담으므로, 여기서 다시 가공하면 측정값이 흐려진다.
중계 읽기 타임아웃은 10분이다 — 100장이 38.5초인데(4단계) 중계가 먼저 끊으면
"커넥터가 느리다" 로 잘못 읽는다.

## 4. 채점은 화면에서 — 서버에 상태를 남기지 않는다

리포트는 화면에 띄우고, **저장할 때만** 파일로 내려간다(PV 보관 없음 · 기획 §0-4).

채점 규율을 코드에서 지킨다. 1~4단계에서 데여서 생긴 것들이다.

| 규율 | 왜 |
|---|---|
| 자리별 O/X 를 **전체 텍스트 검색으로 만들지 않는다** — 값별 **출현 횟수**로 센다 | 1단계에서 한 군데만 남아도 그 값의 모든 자리가 X 로 찍혔다 |
| 쪼개진 값은 **기대값**으로 채점한다 | 문서에 완성된 값이 없어도 정답은 있다. 3단계에서 정답이 0건이 됐다 |
| 거절도 **결과로 표에 남긴다** | 4단계에서 거절을 성공처럼 세어 처리율이 거꾸로 나왔다 |

화면에 실측 숫자를 안내로 박았다 — **동시 5건이 한계**, **100장 38.5초**,
hwp·hwpx 는 변환본이라 포맷 간 PII 출현 횟수가 다를 수 있음.

## 5. 만들면서 걸린 것 둘

### 5.1 API 경로를 하드코딩해서 admin-fe 에서 404 였다

이 화면은 두 곳에서 열린다.

| 어디서 | API base |
|---|---|
| 수집기가 직접 서빙 | `''` |
| **admin-fe 사본** | `'/voice'` (nginx 가 `/voice/` 를 떼서 수집기로) |

`'/api/v1/voice/simulator/doc-deid'` 를 그대로 박았더니, admin-fe 에서 열면 그 경로가
**커넥터로** 가서 404 가 됐다. **사용자는 admin-fe 사본을 연다** — 그대로 뒀으면 탭이
아예 동작하지 않았다.

기존 자동 감지값(`API_BASE`)을 호출 때마다 읽는 `ddApi()` 로 바꿨다. 상수로 미리
만들어 두면 감지가 끝나기 전 빈 값이 박히므로 **함수**로 둔다. 같은 이유로 목록도
`DOMContentLoaded` 에서 받지 않고 탭을 처음 열 때 받는다(`ddOnShow` — 다른 탭과 같은 방식).

### 5.2 404 본문을 JSON 으로 파싱해서 원인을 가렸다

배포 전 화면에서 `Unexpected token '<'` 가 떴다. 404 본문이 HTML 인데 그대로 파싱해서
생긴 메시지다. **진짜 원인(수집기 미배포 · 프로필)이 그 문구에 가렸다.**

상태를 먼저 보고, 안 되면 **무엇을 확인해야 하는지와 부른 주소**를 같이 보여 준다.

> 둘 다 "화면이 안 뜬다" 가 아니라 **"뜨는데 틀린 곳을 부른다"** 류다.
> 정적 파일로 로컬 서빙해 콘솔을 보고 잡았다 — 파일을 그냥 열면 스냅샷이라 JS 가 안 돈다.

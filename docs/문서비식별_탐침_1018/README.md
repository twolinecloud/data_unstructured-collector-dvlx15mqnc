# 문서 비식별 탐침 산출물 (2026-10-18)

읽는 순서는 [1단계 탐침결과](../문서비식별_1단계_탐침결과_1018.md) → 여기.

| 파일 | 무엇 |
|---|---|
| `채점표.md` | 포맷별 원시 채점(값별 추출/잔존 횟수 · 파트별 잔존 · 불린 규칙 id) |
| `주민번호_꼴별_결과.txt` | 체크섬 맞음/틀림 · 하이픈 유무별 실측 — §2.1 의 근거 |
| `{포맷}.추출.txt` | AI-R 이 문서에서 꺼낸 텍스트(`detectedData`) |
| `{포맷}.마스킹.txt` | AI-R 이 돌려준 마스킹 결과(`maskedData`) |
| `answers.json` | 정답표(값 · 자리 · 종류) — 채점 기준 |
| `시험문서/` | 6포맷 시험 문서 + 정답표. **채팅 실화면에서 같은 파일로 재시험용** |

## 시험문서 주의

- 같은 내용을 6포맷으로 낸 것이다. docx 가 원본이고 hwp · hwpx · pdf 는 **한글로 변환**했다.
  변환에서 머리말 · 문서속성 일부가 빠져 **포맷 간 PII 출현 횟수가 다르다**
  (docx 20회 · hwpx 16회). 포맷을 정면 비교할 때는 각 포맷을 직접 생성해야 한다.
- 주민번호는 세 꼴을 넣었다 — **체크섬 맞음**(잡혀야 한다) · **체크섬 틀림**(안 잡힌다 · 함정 기록)
  · **하이픈 없음**(체크섬 맞아도 안 잡힌다 · 진짜 구멍).
- 실데이터 없음. 전부 가상이고 교정번호는 `DMY-` 대역을 쓴다.

생성·채점 도구는 [`tools/문서비식별/`](../../tools/문서비식별/) 에 있다.

## 1. 쉬운 설명 — 무엇이 달라졌나

**전에는** 일 단위 자동 생성(매일 01:30 에 어제 날짜로 대시보드 더미를 만들고, 7일 지난 더미를 지우는 일)을 켜려면
설정 파일을 바꾸고 다시 배포해야 했다. 켜져 있는지 화면에서 볼 방법도 없었고, 7일 삭제가 맞게 도는지 보려면 일주일을 기다려야 했다.

**이제는** 시뮬레이터 맨 위 [일 단위 자동 생성 스케줄러] 패널에서

1. **지금 켜져 있는지** 본다 — 배지 `활성화(ON)` / `비활성화(OFF)`, 다음 실행 시각, 그 값이 설정에서 왔는지 화면에서 바꾼 것인지.
2. **스위치로 켜고 끈다** — 다시 배포할 필요 없다. 켠 값은 PV 파일 `{ROOT}/mock/auto_generator.json` 에 적어 두어서
   파드가 다시 떠도(배포 · 재기동) 그대로 간다. 끄면(= 설정 기본값) 그 파일을 지운다 → 설정이 다시 정한다.
3. **[즉시 실행 (1일 치 생성)]** — 새벽을 기다리지 않고 지금 한 번. 고른 날짜(기본 어제) 치를 만들고, 그 다음 날을 실행일로 보고 7일 지난 것을 지운다.
4. **[7일 경과 시뮬레이션]** — 일주일을 기다리는 대신 "가상의 하루" 를 8번 넘긴다.

```
 가상 실행일  09-28  09-29  …  10-04  10-05(오늘)
 만드는 날짜  09-27  09-28  …  10-03  10-04
 지우는 기준  09-21  09-22  …  09-27  09-28 이전  ← 마지막 회차에서 첫날 만든 09-27 치가 지워진다
```

끝나면 날짜별 건수를 세어 "09-27 은 0건(지워짐) · 09-28 ~ 10-04 는 남아 있음" 이 맞는지 표로 보여 준다(PASS / FAIL).
즉시 실행 · 시뮬레이션은 스위치(ON/OFF)와 상관없이 돈다. 둘이 겹치면(또는 새벽 스케줄과 겹치면) 나중 것은 "실행 중" 으로 거절된다(409).

## 4. 주의

- **이미지(B안) — 실제 처리 기록이 가장 오래된 실패 배치에 남는다.** 이번 시험에서도 09-25 건의 재수집 성공 행은 `20261003UNS002` T4 에 새 키로 들어갔다. UNS007 은 '지금 매핑돼 있음' 으로 해결 처리됐다. 화면의 최종 상태(SUCCESS · 버튼 사라짐)는 맞다.
- **음성 — 구간이 겹치는 배치**(시험용 수동 30일 배치 등)는 앞 배치가 뒤 배치 구간의 건까지 처리하면서 자기 T4 에 성공 행이 늘어난다(`20261003UNS001` 성공 2 → 8). 정기 배치는 구간이 겹치지 않으므로 운영에서는 드물다.
- 다시 연 배치의 `trigger_by` 는 누른 사람/재처리 표식(`…/reprocess:{누른 배치}`)으로 바뀐다(PL reopen API 동작).
- 로그 컬렉터가 V19 없는 DB 를 만나면 덮어쓰지 않고 쌓는다. 이 경우 T1 건수가 부풀 수 있으므로 V19 적용을 먼저 확인한다(개발계 적용됨).

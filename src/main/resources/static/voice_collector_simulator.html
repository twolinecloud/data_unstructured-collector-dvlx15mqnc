디렉터리
ROOT_DIR
ROOT_DIR 은 OS 로 자동 감지 — Windows C:/k8s/voice_collector, Linux/K8s /k8s/voice_collector. 표준 배치: xvram/original_voice_files · esb/meet · esb/phone · xvram/decoding · xenon/meet/{execId} · xenon/phone/{execId} (없으면 자동 생성). ESB 수신(접견) 폴더는 로컬 브로커의 BROKER_OUTPUT_DIR 과 같아야 합니다 — [브로커 연결 확인] 으로 대조.
연동 상태 — DB · 브로커 · 로그 컬렉터 배치를 돌리기 전에 여기서 먼저 대조하십시오
두 경로가 어긋나면 브로커는 "추출 완료" 를 돌려주는데 수집기는 빈 폴더를 봅니다
